# Control de Ingresos y Egresos

App local de escritorio para llevar el control de ingresos por condominio, gastos fijos (recurrentes) y variables, y bolsillos de ahorro con saldo propio.

## Uso

Requiere [Node.js](https://nodejs.org).

```bash
npm install
npm start
```

Se abre automáticamente en `http://localhost:4173`. Los datos se guardan localmente en `data.json` (no se sube a este repositorio).

En Windows también puedes hacer doble clic en `iniciar.bat`.
